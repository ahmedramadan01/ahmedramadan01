## Featured project

### [QueueUp](https://github.com/ahmedramadan01/queueup) — Virtual queue-management SaaS

QueueUp helps businesses replace physical waiting lines with digital queues. A business creates a queue and shares a QR code; customers scan it, join without installing an app, and follow their position and estimated waiting time.

The project is designed around real backend engineering challenges:

- Safe queue ordering under concurrent requests
- Transactional **call-next** operations that prevent two employees from claiming the same customer
- Real-time position updates using Server-Sent Events or WebSockets
- Role-based access for business owners and employees
- PostgreSQL persistence and Flyway database migrations
- Integration and concurrency testing with Testcontainers
- Containerized local development with Docker Compose

**Stack:** Java · Spring Boot · PostgreSQL · React · TypeScript · Docker

> QueueUp is currently under active development.
